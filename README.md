## About Me

I am a **Computer Science Engineering** student at **B.M.S. College of Engineering (BMSCE), Bengaluru**, specializing in **Applied Generative AI** and **Scalable Full-Stack Systems**. I focus on transforming real-world engineering challenges into robust, production-ready software — from multi-provider LLM orchestration and semantic vector retrieval to computational CAD geometry systems.

- 🔭 **Current Focus**: Building resilient backend systems, LLM orchestration engines, and high-throughput microservices.
- 🛠️ **Engineering Principles**: Modular domain boundaries, clean API contracts, hermetic testing, and high developer velocity.
- 💡 **Core Technical Stack**:
  - **Languages**: Java, Python, TypeScript, SQL, C
  - **Backends & Frameworks**: FastAPI, Next.js, Node.js, Express, React, Tailwind CSS
  - **Data & Infrastructure**: PostgreSQL (`pgvector`), Supabase, Neon Serverless, Docker, Git, RESTful APIs
- 🚀 **Featured Systems**:
  - **[ForgeIQ](https://github.com/bhuvanabcs24-maker/Forge-IQ)** — Manufacturing intelligence & automated CAD sheet-metal feature extraction and quotation engine with dynamic LLM provider routing.
  - **[QueueEstimater](https://github.com/bhuvanabcs24-maker/QueueEstimater)** — Dynamic real-time queue management & wait-time estimation engine with zero-friction QR onboarding.
- ⚡ **Competitive Problem Solving**: Actively sharpening algorithmic thinking on **[LeetCode](https://leetcode.com/u/BHUVANab2006/)** (110+ Solved).
